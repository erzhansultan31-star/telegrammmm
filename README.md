# Telegram Photo Editor Bot / Сурет өңдеу боты

Тіл таңдау (RU/KZ), сурет жүктеу, атын/автор атын қосу, фильтрлер
(Ч/Б, сепия, блюр, резкость), өлшемін өзгерту, preview және жүктеп алу.

## Құрылым

```
telegram_bot/
├── main.py          # бот логикасы, handler-лар, polling/webhook іске қосу
├── locales.py        # RU/KZ мәтіндер сөздігі
├── states.py          # FSM күйлері (диалог қадамдары)
├── keyboards.py       # инлайн батырмалар
├── image_utils.py      # Pillow (мәтін) + OpenCV (фильтрлер) функциялары
├── requirements.txt
├── render.yaml         # Render.com конфигурациясы
└── .env.example
```

## 1. Локалды тест (компьютерде)

1. @BotFather-ден бот жасап, токен алыңыз (`/newbot`).
2. Кітапханаларды орнатыңыз:
   ```bash
   pip install -r requirements.txt
   ```
3. `.env.example` файлын `.env` етіп көшіріп, `BOT_TOKEN`-ды толтырыңыз,
   `WEBHOOK_URL`-ды бос қалдырыңыз.
4. Ортаны жүктеп, ботты іске қосыңыз:
   ```bash
   export BOT_TOKEN=сіздің_токен   # Windows: set BOT_TOKEN=...
   python main.py
   ```
5. Telegram-да ботқа `/start` жазыңыз.

## 2. Render.com-ға тегін deploy ету

1. Осы папканы GitHub репозиторийіне жүктеңіз (push).
2. [render.com](https://render.com) сайтында тіркеліп, **New → Web Service**
   таңдап, GitHub репозиторийіңізді байланыстырыңыз. `render.yaml` файлы
   бар болғандықтан Render баптауларды өзі оқиды (Blueprint).
3. Environment Variables бөлімінде толтырыңыз:
   - `BOT_TOKEN` — @BotFather-ден алған токен
   - `WEBHOOK_URL` — deploy болғаннан кейін Render беретін сілтеме,
     мысалы `https://telegram-photo-bot.onrender.com` (соңында `/` қоймаңыз)
4. Deploy болғаннан соң бот автоматты түрде webhook орнатады
   (`main.py` ішіндегі `on_startup` функциясы).
5. Ескерту: тегін тарифте сервис 15 минут белсенді болмаса ұйықтап
   қалады. Telegram webhook хабарлама келген сәтте оны оятады, бірақ
   алғашқы жауап 10-30 секундқа кешігуі мүмкін. Бұл тегін тарифтің
   шектеуі — толық 24/7 жылдам жұмыс үшін ақылы тариф керек.

## Функцияларды кеңейту идеялары

- Пайдаланушы тілін/баптауларын файлға немесе SQLite-қа сақтау
  (қазір тек жады — Render рестарт жасаса жоғалады).
- Шрифт пен мәтін түсін таңдау батырмалары қосу.
- Бірнеше суретті бірден өңдеу (batch).
- Premium режим (су таңбасыз, HD экспорт).
- Admin статистикасы (/stats командасы).
