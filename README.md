# Telegram Music Tag Editor Bot / Музыка тегтерін өңдеу боты

Тіл таңдау (RU/KZ), MP3 файл жүктеу, ән атын/автор (орындаушы) атын
өзгерту, мұқаба (cover) қою, ән туралы ақпаратты көру, тыңдап
көру/жүктеп алу, және iTunes арқылы музыка іздеп табылған атын/
авторын/мұқабасын өз әніңе бір батырмамен қолдану.

## Авторлық құқық туралы ескерту

Музыка іздеу — Apple-дың ашық **iTunes Search API** арқылы жұмыс
істейді. Бұл API тек ән атауын, орындаушысын, мұқабасын және
30 секундтық ресми preview сілтемесін қайтарады. Бот **толық ән
файлдарын интернеттен жүктемейді және таратпайды** — пайдаланушы
тек **өзінің жеке mp3 файлына** тег/мұқаба қосу үшін пайдаланады.

## Құрылым

```
telegram_bot/
├── main.py           # бот логикасы, handler-лар, polling/webhook іске қосу
├── locales.py         # RU/KZ мәтіндер сөздігі
├── states.py           # FSM күйлері (диалог қадамдары)
├── keyboards.py        # инлайн батырмалар
├── audio_utils.py       # ID3 тег оқу/жазу (mutagen): атын, авторын, мұқабасын
├── music_search.py      # iTunes Search API арқылы музыка іздеу
├── requirements.txt
├── render.yaml          # Render.com конфигурациясы
└── .env.example
```

## 1. Локалды тест (компьютерде)

1. @BotFather-ден бот жасап, токен алыңыз (`/newbot`).
2. Кітапханаларды орнатыңыз:
   ```bash
   pip install -r requirements.txt
   ```
3. `.env.example` файлын `.env` етіп көшіріп, `BOT_TOKEN`-ды толтырыңыз,
   `WEBHOOK_URL`-ды бос қалдырыңыз.
4. Ортаны жүктеп, ботты іске қосыңыз:
   ```bash
   export BOT_TOKEN=сіздің_токен   # Windows: set BOT_TOKEN=...
   python main.py
   ```
5. Telegram-да ботқа `/start` жазыңыз.

## 2. Render.com-ға тегін deploy ету

1. Осы папканы GitHub репозиторийіне жүктеңіз (push).
2. [render.com](https://render.com) сайтында тіркеліп, **New → Blueprint**
   таңдап, GitHub репозиторийіңізді байланыстырыңыз (`render.yaml` бар
   болғандықтан баптауларды өзі оқиды).
3. Environment Variables бөлімінде толтырыңыз:
   - `BOT_TOKEN` — @BotFather-ден алған токен
   - `WEBHOOK_URL` — deploy болғаннан кейін Render беретін сілтеме
     (соңында `/` қоймаңыз)
4. Deploy болғаннан соң бот автоматты түрде webhook орнатады.
5. Ескерту: тегін тарифте сервис 15 минут белсенді болмаса ұйықтап
   қалады, webhook хабарлама келгенде оянады (алғашқы жауап
   10-30 секундқа кешігуі мүмкін).

## Функционал

| Батырма | Не істейді |
|---|---|
| 🎵 Ән жіберу | mp3 файлды жүктеп, ботпен жұмысты бастайды |
| ✏️ Атын өзгерту | ID3 TIT2 тегін жаңартады |
| 👤 Авторды өзгерту | ID3 TPE1 тегін жаңартады |
| 🖼 Мұқаба қою | суретті ID3 APIC фреймі ретінде ендіреді |
| 🔍 Музыка іздеу | iTunes API-ден іздеп, нәтижелерді көрсетеді |
| ✅ Осыны қолдану | табылған атын+авторын+мұқабасын өз әніңе қолданады |
| ℹ️ Ақпарат | ағымдағы атын/авторын/мұқаба бар-жоғын көрсетеді |
| 👁 Тыңдап көру | Telegram ішінде audio-player арқылы ойнатады |
| 📥 Жүктеп алу | дайын mp3 файлды жібереді |

## Кеңейту идеялары

- Пайдаланушы файлдарын SQLite-қа сақтау (қазір тек жады —
  Render рестарт жасаса жоғалады).
- Альбом атын (TALB), жанрын (TCON), жылын (TYER) өзгерту.
- Бірнеше файлды бірден өңдеу (batch).
- iTunes preview-ды (`preview_url`) тікелей тыңдап көру батырмасы.
